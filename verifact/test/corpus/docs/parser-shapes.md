# 语料：解析器形状

这一份文档不含任何数值声明。它存在的唯一目的是把三种曾经把真实门禁打挂的
形状固定进语料：围栏里的指令示例、行内代码里的指令示例、以及未闭合围栏。

**示例一**：围栏中的指令示例。它看起来像一条声明，但它在代码围栏里，必须被掩蔽。

````md
<!-- verifact: disposition=narrative why="example inside a fence" -->
````

**示例二**：行内代码 `<!-- verifact: disposition=narrative -->` 同样只是文本，不是声明。
